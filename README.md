# Softspot · 桌面小伙伴

将自己的图片变成会回应的桌宠。使用 Electron，支持 macOS 与 Windows。完整调研见仓库的 `content/AI_Desktop_Pet.md`。

## 运行

从**博客仓库根目录**执行，需要 Node.js 22.12 或以上：

```sh
npm --prefix demos/desktop-pet ci
npm --prefix demos/desktop-pet start
```

关闭小窝窗口后，应用仍在菜单栏／系统托盘运行。彻底退出请使用托盘菜单「退出 Softspot」。

## 体验路径

1. 不配置密钥也可体验内置小猫、摸摸、投喂、一起玩、睡眠和本地规则回应。
2. 点击「换个模样」，上传 PNG、JPG 或 WebP，最大 8 MB、3200 万像素。图片在本机缩小到最长边 1024 像素。
3. 默认尝试去掉与边缘相连的纯色背景。这是确定性算法，不是 AI 分割；白色主体可能被误删，可取消勾选再导入。
4. 点击「连接 AI」，填写 API 地址、密钥、对话模型与图片编辑模型。
5. 点击「AI 转化为绒毛伙伴」。这一步才把导入图片发送至你的 AI 服务，可能收费。失败保留原有图片。
6. 在「陪伴」中聊天，在「小小记忆」中添加偏好，点击「放到桌面」打开透明置顶窗口。
7. 轻点桌宠摸摸，拖动它调整位置。透明空白区域可穿透鼠标，托盘也可切换整个桌宠窗口完全穿透。

内置小猫是本地 Canvas 程序绘制的实际可互动角色，有随情绪变化的眼睛。上传／AI 转化后的角色使用整图呼吸、弹跳、摇摆和睡眠动画；这一版**没有自动生成分层骨骼、逐帧动画或独立面部表情**。

## AI 接口

默认对话模型：`gpt-4.1-mini`；默认图片模型：`gpt-image-1.5`。它们是可修改的接口起点，不是对所有供应商都可用的承诺，也不宣称是当前最新模型。

| 用途     | 接口约定                                                                                   |
| -------- | ------------------------------------------------------------------------------------------ |
| 聊天     | `POST {base}/chat/completions`，支持 `response_format: json_object`                        |
| 图片编辑 | `POST {base}/images/edits`，Multipart `image`，透明 PNG，返回 `data[0].b64_json`           |
| 情绪输出 | `{"reply":"…","emotion":"calm/happy/curious/sleepy/sad"}`，其中 `emotion` 必须是一个枚举值 |

使用不同供应商时，要确认**图片编辑**接口及参数兼容，不能只确认聊天兼容。国内部署可更换网关或实现对应供应商适配器；Seedream 等不同图片协议需要单独适配。本地 Ollama 等仅提供聊天能力时，图片生成仍需另一项服务；本 Demo 暂时共用一套连接设置。

也可以通过进程环境变量配置，不要将密钥写入仓库：

- `PET_AI_BASE`：API 基础路径，包含 `/v1`。
- `PET_AI_KEY`，或 `OPENAI_API_KEY`：会话密钥。
- `PET_CHAT_MODEL`、`PET_IMAGE_MODEL`：模型 ID。
- `PET_DATA_DIR`：覆盖本地数据目录，供隔离测试使用。

连接设置只在本次进程内有效；「AI 已配置」表示配置完成，不表示服务已经通过联网验证。聊天请求超时为 30 秒，失败或 JSON 不合约时明确标记「本地回退」。图片请求超时为 150 秒；超时不代表服务端取消，连续重试可能重复计费。

## 数据与桌面行为

- 使用 Electron 的 `userData` 目录保存 `companion.json`、`source.png` 与 `pet.png`。`source.png` 是导入时缩放／可选去底后的版本，不保留相机原始文件或 EXIF。
- 保存名字、性格、三项状态、最近 24 条消息、最多 8 条显式记忆及拖动后的位置。
- 本地规则回应并非大模型；情绪是可解释的行为模拟，不代表真实感情或意识。
- 云端聊天会发送最近 16 条历史消息、当前消息、宠物状态和全部显式记忆。删除记忆后不再注入该条；历史中重复提及的内容仍需通过「清空」聊天删除。
- 密钥仅在主进程内存中；渲染进程不拿回密钥，不写入本地存储。
- 小窝与桌宠使用同一主进程状态；磁盘状态采用临时文件后重命名。
- 透明空白穿透以元素矩形为粒度，**不是按图片 Alpha 像素穿透**。
- 系统休眠恢复按时间差更新，最多补算 8 小时；不会因为几天没打开就反复惩罚用户。

## 验证与打包

```sh
# Electron 原生窗口 E2E；AI 部分使用本机模拟服务，不产生云端调用费用
npm --prefix demos/desktop-pet run test:e2e

# 在 macOS 上创建本机架构的 .app
npm --prefix demos/desktop-pet run pack:mac

# 创建 Windows x64 ZIP（可跨平台打包，运行验收必须在 Windows 上做）
npm --prefix demos/desktop-pet run pack:win

# macOS Apple Silicon + Intel ZIP
npm --prefix demos/desktop-pet run dist:mac
```

结果在 `demos/desktop-pet/dist/`；E2E 的报告与截图在 `test-results/`，不提交生成物。使用固定依赖和 `package-lock.json`。

打包配置用于开发 Demo，尚无 Apple Developer ID 签名、公证和 Windows 代码签名。跨平台产物不能替代对应系统的安装、透明窗口、缩放、多显示器和托盘验收。

## 视觉与范围

- 视觉：奶油纸色、陶土红、单一角色居中，安静而有温度。
- 内容：左侧直接照顾宠物，右侧切换聊天、图片和记忆；主操作为「放到桌面」。
- 动效：呼吸体现陪伴感；摸摸弹跳回应输入；睡眠降低节奏；支持系统减少动画设置。
- 没有屏幕读取、语音、账号、多宠物、开机自启或云同步。
- 后续建议先验证参考图一致性与 3 种情绪差分图，再考虑 2D 骨骼或 Live2D。
