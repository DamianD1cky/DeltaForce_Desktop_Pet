# Delta Companion

面向国内游戏《三角洲行动》的非官方像素角色桌宠，目标角色为威龙和红狼。以角色形象还原、像素立绘及逐帧互动为核心，使用 Electron 构建 macOS 与 Windows 桌面应用。

本项目不隶属于游戏官方，不读取客户端、屏幕、账号、战绩或对局数据。当前定位是离线优先的桌面伴侣，而非游戏数据助手。

## 角色美术进度

已根据 `asset/pic/` 的 4 张参考图制作红狼「蚀金玫瑰」正面像素立绘样稿：`192 × 288` 原生像素、30 色、透明背景。

红狼已成为应用默认桌宠。基于该立绘生成 253 帧离线像素资产，在统一的 `320 × 320` 透明画布中以 25 FPS 播放，显示尺寸为 `240 × 240` CSS 像素，包含待机、休息、滑铲、捏爆金玫瑰和右臂手炮。见 [角色与动作说明](asset/sprites/redwolf-gilded-rose/README.md) 和 [动作分镜](asset/sprites/redwolf-gilded-rose/actions-review.png)。威龙参考图尚待补充。

## 当前能力

- 红狼「蚀金玫瑰」像素桌宠：黑金外骨骼、骷髅面具、胸前玫瑰与右前臂手炮。
- 三种可点击的专属动作，行动台与桌面浮窗按同一时间轴同步。
- 状态确认、补给、模拟演练和休整互动。
- 透明置顶桌面窗口、拖动定位、空白区域鼠标穿透和托盘常驻。
- 导入 PNG、JPG 或 WebP 图片作为自定义角色，支持确定性的本地纯色去底。
- 保存单位代号、响应风格、三项状态、最近 24 条通讯、最多 8 条本地档案和桌面位置。
- 可选接入 OpenAI 兼容服务，用于自由对话和战术风格图片编辑。
- 主进程与渲染进程隔离，API Key 仅保留在当前进程内。

## 运行

需要 Node.js 22.12 或更高版本：

```sh
npm ci
npm start
```

关闭行动台后，应用仍在菜单栏或系统托盘运行。彻底退出请使用托盘菜单「退出 Delta Companion」。

## 使用路径

1. 启动后可直接使用红狼和三种专属动作，不需要配置 API Key。
2. 在「外观」中导入图片。文件最大 8 MB、3200 万像素，并会在本机缩放到最长边 1024 像素。
3. 可选启用「移除纯色背景」。该功能不是 AI 分割，主体颜色接近背景时建议关闭。
4. 点击「部署到桌面」打开透明置顶伙伴窗口。
5. 如需自由对话或生成战术外观，在「接入 AI」中填写服务地址、密钥和模型 ID。
6. 在「档案」中记录需要长期保留的偏好；删除条目后不会再注入后续 AI 对话。

## 红狼专属动作

行动台与桌面浮窗均可点击「滑铲」「捏爆金玫瑰／捏玫瑰」「右臂手炮／手炮」。

| 动作             | 画面表现                                                                            | 帧数 / 时长     |
| ---------------- | ----------------------------------------------------------------------------------- | --------------- |
| 滑铲             | 屈膝蓄力、伸腿滑行、脊柱缓冲、制动收腿、起身；桌面窗口向右移动最多 150 像素，在当前屏幕工作区边缘停止 | 48 帧 / 1.92 秒 |
| 大招：捏爆金玫瑰 | 抬手举起一朵金玫瑰、逐渐收拢手指、捏碎花朵、金色花瓣飞散、沿弧线收手              | 69 帧 / 2.76 秒 |
| 右臂手炮         | 肩肘带动抬臂、瞄准发射、胸颈吸收后坐、缓冲复位；正面视角右臂在画面左侧            | 36 帧 / 1.44 秒 |
| 待机             | 腰胸呼吸、头部与手臂轻微随动                                                      | 40 帧 / 1.60 秒 |
| 休整             | 缓慢呼吸、低头与上浮的休息符号                                                    | 60 帧 / 2.40 秒 |

动作结束自动返回待机，不可叠加释放。休息、换图、隐藏或拖动会中断动作；休息时需先叫醒。系统启用「减少动画」时展示动作关键帧，并取消窗口滑行。像素角色不使用整图旋转、缩放或 CSS 摇摆。

自定义静态图片不具备红狼的动作；在「外观」点击「恢复红狼 · 蚀金玫瑰」可恢复内置角色及动作。旧版默认机器人会迁移为红狼；已有自定义图片、档案与通讯记录保留。动作播放进度不写入存档，重启不会重放大招。

动作根据用户描述进行像素化演绎，尚无游戏内动作视频用于逐帧匹配；没有宣称与原游戏动作节奏完全一致。

## AI 接口

默认对话模型为 `gpt-4.1-mini`，默认图片模型为 `gpt-image-1.5`。模型 ID 可以修改，不代表所有兼容服务都提供相同能力。

| 用途     | 接口                                                |
| -------- | --------------------------------------------------- |
| 对话     | `POST {base}/chat/completions`，响应内容为 JSON     |
| 图片编辑 | `POST {base}/images/edits`，返回 `data[0].b64_json` |
| 情绪     | `calm`、`happy`、`curious`、`sleepy`、`sad`         |

可通过环境变量配置：

- `PET_AI_BASE`：API 基础路径，需要包含 `/v1`。
- `PET_AI_KEY` 或 `OPENAI_API_KEY`：会话密钥。
- `PET_CHAT_MODEL`：对话模型 ID。
- `PET_IMAGE_MODEL`：图片编辑模型 ID。
- `PET_DATA_DIR`：覆盖本地数据目录，主要用于隔离测试。

对话请求超时为 30 秒，失败后明确回退到本地协议。图片请求超时为 150 秒；超时不表示上游服务已经取消，避免连续重试产生重复费用。

## 本地数据与隐私

应用在 Electron `userData` 目录保存：

- `companion.json`：角色配置、状态、通讯、档案和窗口位置。
- `source.png`：导入、缩放和可选去底后的原始角色素材。
- `pet.png`：当前桌面角色图像。

云端对话会发送最近 16 条通讯、当前消息、角色状态和全部显式档案。图片只有在执行「AI 生成战术外观」时才会发送。API Key 不写入磁盘，也不暴露给渲染进程。

## 验证与打包

```sh
npm run test:e2e
npm run pack:mac
npm run pack:win
npm run dist:mac
```

E2E 测试使用本机模拟 AI 服务，不产生云端调用费用。测试结果写入 `test-results/`，打包结果写入 `dist/`。

当前打包配置没有 Apple Developer ID 签名、公证或 Windows 代码签名。跨平台构建不能替代在目标系统上对安装、透明窗口、缩放、多显示器和托盘行为的验收。

## 范围边界

当前版本没有游戏客户端集成、战绩查询、屏幕读取、语音、账号、多角色、开机自启或云同步，也没有 Live2D。动画已离线生成为逐帧图集，不依赖运行时骨骼引擎或云端生图。涉及游戏数据的功能必须在数据来源明确后再实现。
