# 红狼 · 蚀金玫瑰

根据用户提供的 4 张参考图制作的像素角色，已接入 Electron 桌宠。角色来自国内游戏《三角洲行动》，皮肤名称为「蚀金玫瑰」。保留原静态立绘，同时增加基于用户动作描述绘制的逐帧动画。

## 文件

| 文件                        | 用途                                                    |
| --------------------------- | ------------------------------------------------------- |
| `redwolf-idle-front.png`    | 原生 `192 × 288` 像素、RGBA 透明立绘，单帧              |
| `redwolf-idle-front@4x.png` | `768 × 1152` 像素，最近邻 4 倍放大                      |
| `redwolf-review.png`        | 全身 3 倍预览、原尺寸预览、面部 5 倍局部与胸部 4 倍局部 |
| `sprite.json`               | 尺寸、实际色数、角色边界、参考图来源及绘制用色板        |
| `animations.json`           | 应用使用的图集文件名、帧数、时长、静态关键帧和滑行距离  |
| `*-atlas.png`               | 透明 PNG 图集，每格 `320 × 320` 像素，每行 10 格        |
| `*-preview.gif`             | 独立循环动画预览，实色背景仅用于预览                    |
| `actions-review.png`        | 四套动作的关键姿势分镜                                  |

原生图实际使用 30 种不透明颜色；Alpha 只有 `0` 和 `255`。预览板文字、底色不属于角色资源。

- [红狼-3.png](../../pic/红狼-3.png)：背面特写，确认背包、背带及天线。

绘制时逐项参考这些特征，在整数像素坐标上重建形体、明暗和色块。原始参考图保持不变，未发送给外部图像服务。

## 本版取舍与待确认内容

- 姿势：正面站立、双手下垂；由参考图的展示姿势改为便于桌宠使用的待机姿势。
- 比例：约 5 头身，头部相较参考图放大，用于小尺寸呈现面具；尚未确认最终是否改为更修长的比例。
- 配色：黑灰装备、旧金金属、银白头发。深色装备适度提亮，使其在深色桌面上有层次。
- 细节：保留金玫瑰、面具孔槽、麦克风、肩臂外骨骼、髋膝金色部件和小腿支架；简化布料纹理、暗纹、微小文字和紧固件。
- 当前不足：金玫瑰花瓣、复杂胸部外骨骼和布料质感仍是像素概括；本样稿不代表最终还原度通过验收。
- 已有待机、休息、滑铲、捏爆金玫瑰、三连发右臂手炮和黑金烟雾弹。没有侧背面与行走动画；威龙需其对应参考图。

## 动作资产

共 714 帧，以 50 FPS（每帧 20 ms）播放：待机 80 帧、休息 120 帧、滑铲 96 帧、大招 138 帧、手炮 100 帧、烟雾弹 180 帧。中间帧由关节轨迹重新采样生成；静止蓄势和像素量化可能保留相同画面。

身体从 16 分段细化为 22 分段：腿部各 4 段、躯干和头颈 6 段、双臂及手掌各 4 段；双手另外有 16 段手指关节。新增腰胸分段、独立肩甲、颈部与足掌，手掌跟随手腕转动。单调三次插值维持关键姿势间连续速度，避免每段过渡都从静止重新启动。

- 右前臂装置固定在角色的解剖学右侧，即正面视图的画面左侧。所有动作均不镜像。
- 大招使用手中的独立金玫瑰，包含举花、握紧、花朵被捏碎、花瓣飞散与收手；胸前玫瑰仍是服饰配件。
- 滑铲进一步降低胸颈和头部高度，双手随身体接近地面；先屈膝蓄力，再伸腿压低重心，滑行中躯干逐级吸收震动，制动后收腿、蹬地起身。护膝、靴子与腿部支架沿用立绘纹理。
- 手炮在 560、800、1040 ms 分别发射，炮口闪光约放大 50%，弹体更粗；每发独立后坐，头部延迟 40 ms 吸收冲击。发射事件记录在 `animations.json`。
- 烟雾弹包含取弹、后摆、投掷、跟随收手；760 ms 脱手、1240 ms 落地出烟，黑色烟团由多层团块组成，内部金色粒子流动，末段通过像素网点消散，保持透明背景。
- 捏花增加连续收指和花瓣运动；待机与休整均有腰胸呼吸、头部和手臂随动。
- 离线制作时对肢体部件进行姿势调整和最近邻采样，输出到统一整数像素网格；运行时只播放图集帧，不实时旋转或拉伸整图。
- 描述和静态图是本版动作依据，尚无原游戏动作视频做帧时序与造型对照。

## 再生成

脚本为 [`scripts/draw-redwolf.py`](../../../scripts/draw-redwolf.py)，只用于美术资源生成，不是 Electron 的运行时依赖。

在仓库根目录运行：

```sh
python3 -m venv .venv-art
.venv-art/bin/python -m pip install -r scripts/requirements-art.txt
.venv-art/bin/python scripts/draw-redwolf.py
.venv-art/bin/python scripts/animate-redwolf.py
```

Windows 可使用 `.venv-art\Scripts\python.exe`。预览板需要支持中文的字体，脚本会寻找系统字体；也可设置 `PIXEL_ART_FONT` 为本机中文字体路径。脚本内含透明度、调色板和非空图像检查。

行动台和桌面浮窗均按 `240 × 240` CSS 像素显示 `320 × 320` 图集帧，比原显示尺寸缩小 25%，采用最近邻渲染；禁用像素角色的 CSS 旋转、动态缩放与整图呼吸。发布包仅包含运行所需图集和 `animations.json`，不包含参考截图及生成脚本。
