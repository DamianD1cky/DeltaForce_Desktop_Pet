# 红狼 · 蚀金玫瑰

根据用户提供的 4 张参考图制作的像素角色，已接入 Electron 桌宠。角色来自国内游戏《三角洲行动》，皮肤名称为「蚀金玫瑰」。保留原静态立绘，同时增加基于用户动作描述绘制的逐帧动画。

## 文件

| 文件                        | 用途                                                    |
| --------------------------- | ------------------------------------------------------- |
| `redwolf-idle-front.png`    | 原生 `192 × 288` 像素、RGBA 透明立绘，单帧              |
| `redwolf-idle-front@4x.png` | `768 × 1152` 像素，最近邻 4 倍放大                      |
| `redwolf-review.png`        | 全身 3 倍预览、原尺寸预览、面部 5 倍局部与胸部 4 倍局部 |
| `sprite.json`               | 尺寸、实际色数、角色边界、参考图来源及绘制用色板        |
| `animations.json`           | 图集文件名、格位裁切、帧时长、帧到格位的映射、静态关键帧、事件和滑行曲线 |
| `*-atlas.png`               | 透明 PNG 图集；每格只保留该动作所有帧的公共包围盒        |
| `*-preview.gif`             | 独立循环动画预览，实色背景仅用于预览                    |
| `actions-review.png`        | 四套动作的蓄力、发力与收势分镜                          |
| `motion-review.png`         | 四套动作的关节轨迹：每点 20 ms，弧线与点距对应转动和缓动 |

原生图实际使用 30 种不透明颜色；Alpha 只有 `0` 和 `255`。预览板文字、底色不属于角色资源。

## 本版取舍与待确认内容

- 姿势：正面站立、双手下垂；由参考图的展示姿势改为便于桌宠使用的待机姿势。
- 比例：约 5 头身，头部相较参考图放大，用于小尺寸呈现面具；尚未确认最终是否改为更修长的比例。
- 配色：黑灰装备、旧金金属、银白头发。深色装备适度提亮，使其在深色桌面上有层次。
- 细节：保留金玫瑰、面具孔槽、麦克风、肩臂外骨骼、髋膝金色部件和小腿支架；简化布料纹理、暗纹、微小文字和紧固件。
- 当前不足：金玫瑰花瓣、复杂胸部外骨骼和布料质感仍是像素概括；本样稿不代表最终还原度通过验收。
- 已有待机、休息、入睡、醒来、滑铲、捏爆金玫瑰、三连发右臂手炮和黑金烟雾弹。没有侧背面与行走动画；威龙需其对应参考图。

## 动作资产

共 847 张不重复的帧，时间轴落在 50 FPS（每格 20 ms）网格上；相邻的相同画面合并为更长的帧时长，非相邻的重复画面共用同一格位。待机 8.00 秒 / 117 格，休息 5.60 秒 / 137 格，入睡 1.30 秒 / 52 格，醒来 1.50 秒 / 65 格，滑铲 2.00 秒 / 96 格，大招 2.80 秒 / 121 格，手炮 2.10 秒 / 87 格，烟雾弹 3.60 秒 / 172 格。图集按动作裁切到公共包围盒，每个窗口解码后约占 172 MB（旧版约 295 MB）。

### 骨架

- 3D 骨架正交投影到正面视图：x 向右、y 向下、z 朝向观众；角色面朝 +z，解剖学右侧在画面左侧。
- 骨骼长度恒定。肘、膝是只能向一侧弯曲的铰链；肩、髋是球窝关节。放松站立时肘部约屈 27°，所以侧举的前臂会显示完整的 33 px，而不是被拉长。
- 手臂关键姿势用「手腕目标 + 肘部朝向」做两段式 IK，换算成上臂方向、扭转与屈肘后在关节空间插值：上臂方向取球面上接近最短弧的路径，抬起的手臂横扫时不会下垂，越过身体时也不会绕圈，手和肘沿弧线运动。
- 承重的脚每帧用两段式 IK 固定在地面；站立时膝盖保留立绘的内收并朝观众方向屈曲，深蹲时外展，滑铲时在画面平面内弯曲。
- 关键姿势之间用单调三次插值，速度连续且不过冲；起跳、出手、后坐等瞬间按段使用加速或减速曲线。
- 各关节可整体提前或滞后：投掷时髋、腰、胸依次领先手臂，手炮后坐先到前臂，约 25–35 ms 后到胸腰，头部最后。
- 被动部位（不发力的手臂、手腕、头部）带有旋转弹簧，按惯性产生滞后、轻微过冲和回稳；主动发力的手臂由关键姿势驱动，不加弹簧。弹簧在片段首尾淡出，保证衔接处精确落在静止姿势上。
- 生成时检查每帧位移，超过 26 px / 帧即报错：手部峰值约 24 px / 帧（投掷出手瞬间），其余动作在 18 px / 帧以内，速度曲线呈钟形，没有单帧跳跃。
- 头部会抵消约一半的躯干倾斜，保持视线水平，也减少面部像素的旋转。
- 呼吸会抬起胸廓和肩膀约 1–2 px；待机每 4 秒一次，休息每 5.6 秒一次。

### 像素渲染

- 22 个身体分段和双手 16 段手指关节都沿用立绘原像素。
- 接近原姿态的部位（尖端偏移不足一像素）整像素平移，不重新采样。
- 转动的部位先做 3 次 Scale2x 放大到 8 倍，再按 RotSprite 方式最近邻采样回原尺寸，细线和单像素高光保持连续；角度按「骨骼尖端移动 1 px」量化，慢速转动不会逐帧闪烁。
- 关节先取整再决定部位姿态，亚像素抖动不会让同一姿势产生不同画面。
- 肩甲只跟随上臂转动的一半，其余随躯干，避免抬臂时整块肩甲翻起。

### 动作说明

- 右前臂装置固定在角色的解剖学右侧，即正面视图的画面左侧。所有动作均不镜像。
- 大招使用手中的独立金玫瑰，包含举花、停顿、逐指收拢、捏碎、花瓣沿弹道飞散与收手；胸前玫瑰仍是服饰配件。
- 滑铲先屈膝蓄力并前倾，再蹬地前冲、压低髋部后仰入滑；滑行中地面震动从髋部沿脊柱逐级衰减，前脚制动后收腿到髋下、起身回稳。窗口位移按 `movement.samples` 中「蹬地加速、摩擦减速」的速度曲线进行。
- 手炮在 560、800、1040 ms 分别发射；前臂抬到水平并处于画面平面内，炮口闪光与弹体水平射出。发射事件记录在 `animations.json`。
- 烟雾弹包含取弹、左手拔销、后引蓄力、依次发力投掷和横过身体收势；800 ms 脱手、1220 ms 落地弹跳、1340 ms 起烟。黑色烟团由多层团块组成，内部金色粒子流动，末段通过像素网点消散，保持透明背景。
- 入睡与醒来是休整切换时的过渡片段：末帧分别与休息、待机的第 0 帧一致。
- 运行时只播放图集帧，不实时旋转或拉伸整图。
- 描述和静态图是本版动作依据，尚无原游戏动作视频做帧时序与造型对照。

## 再生成

脚本为 [`scripts/draw-redwolf.py`](../../../scripts/draw-redwolf.py)，只用于美术资源生成，不是 Electron 的运行时依赖。

在仓库根目录运行：

```sh
python3 -m venv .venv-art
.venv-art/bin/python -m pip install -r scripts/requirements-art.txt
.venv-art/bin/python scripts/draw-redwolf.py
.venv-art/bin/python scripts/animate-redwolf.py
```

需要 Python 3.12 或更高版本。Windows 可使用 `.venv-art\Scripts\python.exe`。预览板需要支持中文的字体，脚本会寻找系统字体；也可设置 `PIXEL_ART_FONT` 为本机中文字体路径。脚本内含透明度、画布边界和图集尺寸检查，生成约 10 秒。

行动台和桌面浮窗均按 `240 × 240` CSS 像素显示 `320 × 320` 帧，比原显示尺寸缩小 25%，采用最近邻渲染；禁用像素角色的 CSS 旋转、动态缩放与整图呼吸。播放器按 `cells` 找到图集格位，再画到 `cell` 记录的画布位置。发布包仅包含运行所需图集和 `animations.json`，不包含参考截图及生成脚本。
